## 2. Outline & Struktur Presentasi

### Membuat Outline dengan AI

**Prompt 1 — Outline Presentasi Umum:**
```
Buatkan outline presentasi 15 menit tentang "Manfaat AI
untuk UMKM Indonesia".

Target audiens: pemilik UMKM (non-teknis)
Tujuan: meyakinkan mereka untuk mulai menggunakan AI
Gaya: storytelling + data

Struktur:
1. Opening hook (1 slide)
2. Problem statement (2 slide)
3. Solusi dengan AI (3 slide)
4. Studi kasus nyata (2 slide)
5. Cara memulai (2 slide)
6. Closing & CTA (1 slide)

Untuk setiap slide, berikan:
- Judul slide
- 3-5 bullet points
- Visual yang disarankan
- Catatan presenter
```

**Prompt 2 — Outline Pitch Deck:**
```
Buatkan outline pitch deck untuk startup:
- Nama: EduBot (chatbot AI untuk bimbingan belajar)
- Stage: Seed
- Target investor: angel investor
- Durasi presentasi: 10 menit

Gunakan format:
1. Problem
2. Solution
3. Market size
4. Product
5. Traction
6. Business model
7. Team
8. Ask (funding)
9. Vision
```

### Framework Presentasi

| Framework | Struktur | Cocok Untuk |
|-----------|----------|-------------|
| **PAS** | Problem → Agitation → Solution | Persuasi |
| **STAR** | Situation → Task → Action → Result | Studi Kasus |
| **AIDA** | Attention → Interest → Desire → Action | Marketing |
| **What? So What? Now What?** | Data → Implikasi → Tindakan | Bisnis |
| **3-Act** | Setup → Confrontation → Resolution | Storytelling |

## 3. Content Generation

### Membuat Konten Setiap Slide

**Prompt 3 — Konten dengan Data:**
```
Buatkan konten presentasi untuk slide berikut:
Judul: "Pertumbuhan E-Commerce Indonesia 2020-2025"

Isi yang diharapkan:
1. Data statistik dengan sumber (BPS, eMarketer)
2. Insight dari data
3. Implikasi untuk bisnis
4. Rekomendasi

Gaya bahasa: profesional, data-driven
Format: untuk diubah ke bullet point di slide
```

**Prompt 4 — Storytelling Opening:**
```
Buatkan opening presentasi yang menarik (slide 1-3) untuk
topik "Masa Depan Kerja: AI vs Manusia".

Inginkan:
- Hook cerita yang menarik perhatian
- Data yang mengejutkan
- Pertanyaan retoris
- Transisi ke topik utama

Gaya: Storytelling, bukan ceramah
```

**Prompt 5 — Q&A Preparation:**
```
Saya akan presentasi tentang "Transformasi Digital di
Sektor Pendidikan". Siapkan:
1. 10 pertanyaan yang kemungkinan ditanyakan audiens
2. Jawaban ringkas untuk masing-masing
3. Backup data/fakta untuk mendukung jawaban
4. Cara menangani pertanyaan yang sulit/di luar topik
```

## 4. Speaker Notes

**Prompt 6 — Speaker Notes Lengkap:**
```
Buatkan speaker notes untuk setiap slide presentasi berikut:

Slide 1: "5 Cara AI Meningkatkan Produktivitas Kerja"
Bullet: Email otomatis, Meeting summary, Data analysis,
        Code assistance, Content creation

Slide 2: "Problem: Waktu Terbuang di Aktivitas repetitive"
Bullet: 60% waktu kerja = aktivitas repetitive
        Rata-rata 3 jam/hari untuk email & dokumen

Slide 3: "Solusi: AI-Powered Productivity"
Bullet: Contoh tools, ROI, case study

Untuk masing-masing slide, berikan:
- Kalimat pembuka untuk slide ini
- Penjelasan detail setiap bullet point
- Transisi ke slide berikut
- Tips delivery (jeda, intonasi, gestur)
- Durasi yang disarankan per slide
```

**Prompt 7 — Narasi Storytelling:**
```
Buatkan narasi storytelling untuk presentasi:
"Bagaimana UMKM di Bandung Naik Omzet 300% dengan AI"

Slide flow:
1. Buka dengan cerita Pak Budi (tukang batik)
2. Tantangan yang dihadapi
3. Titik balik: mulai pakai AI
4. Transformasi bisnis
5. Hasil yang dicapai
6. Pelajaran untuk audiens

Tone: Inspirasional, realistis, tidak berlebihan
```

## 5. Desain & Template

### Menggunakan Canva AI

**Langkah-langkah Canva AI untuk Presentasi:**

```
1. Buka canva.com → klik "Presentasi"
2. Pilih ukuran: 16:9 (widescreen)
3. Gunakan "Magic Design":
   - Ketik topik presentasi
   - Pilih style yang diinginkan
   - AI akan generate layout & desain
4. Customize:
   - Ganti warna sesuai brand
   - Upload gambar sendiri
   - Edit teks & font
5. Export sebagai PDF atau PowerPoint
```

**Prompt 8 — Color Palette & Branding:**
```
Saya mau presentasi untuk pitching produk fintech.
Buatkan rekomendasi:
1. Color palette (5 warna dengan hex codes)
2. Font combination (heading + body)
3. Style tone (modern, trustworthy, professional)
4. Visual elements (icons, shapes, patterns)
5. Do's and Don'ts desain
```

## Workflow Presentasi dengan AI

```
┌─────────────────────────────────────────────────┐
│  TAHAP 1: PLANNING (10 menit)                   │
│  • ChatGPT: Buat outline & struktur              │
│  • ChatGPT: Identifikasi audiens & tujuan        │
├─────────────────────────────────────────────────┤
│  TAHAP 2: CONTENT (20 menit)                     │
│  • ChatGPT: Generate konten setiap slide          │
│  • ChatGPT: Buat speaker notes                   │
│  • ChatGPT: Siapkan data & statistik             │
├─────────────────────────────────────────────────┤
│  TAHAP 3: DESIGN (15 menit)                      │
│  • Gamma AI: Generate slide dari outline          │
│  • Canva AI: Customize desain & warna            │
│  • Canva AI: Tambah grafik & visual              │
├─────────────────────────────────────────────────┤
│  TAHAP 4: REFINEMENT (15 menit)                  │
│  • Review semua slide                            │
│  • Cek konsistensi desain                        │
│  • Rehearse dengan speaker notes                 │
├─────────────────────────────────────────────────┤
│  TAHAP 5: PRACTICE (10 menit)                    │
│  • ChatGPT: Simulasi Q&A                         │
│  • Rehearse dengan timer                         │
│  • Siapkan backup (PDF export)                   │
└─────────────────────────────────────────────────┘
Total: ~70 menit untuk presentasi profesional
```

## Tips Presentasi Efektif

| Tips | Penjelasan |
|------|-----------|
| **10-20-30 Rule** | 10 slide, 20 menit, 30pt font minimum |
| **Satu Ide per Slide** | Jangan serakah, fokus pada satu pesan |
| **Gunakan Gambar** | Gambar > teks untuk daya ingat |
| **Storytelling** | Cerita lebih diingat dari fakta |
| **Rehearse** | Latihan minimal 3 kali sebelum presentasi |
| **Backup** | Selalu punya PDF backup jika teknis error |

## Key Takeaways

1. **AI mempercepat proses presentasi** — dari outline hingga desain
2. **Gamma AI & Canva AI** — tool terbaik untuk generate presentasi cepat
3. **Speaker notes sama pentingnya dengan slide** — buat dengan AI
4. **Data visualization memperkuat pesan** — pilih chart yang tepat
5. **Rehearsal tetap diperlukan** — AI buat konten, kamu yang presentasi
6. **Pitch deck butuh practice** — gunakan AI untuk simulasi Q&A

---

## Practice Exercises

1. **Mini Presentation:** Buat presentasi 5 slide tentang "Hobi kamu" menggunakan Gamma AI. Practice presentasi di depan cermin.

2. **Pitch Deck Challenge:** Buat pitch deck untuk bisnis ide kamu. Gunakan AI untuk konten dan Canva untuk desain.

3. **Speaker Notes:** Ambil presentasi lama yang sudah dibuat. Gunakan AI untuk membuat speaker notes lengkap.

4. **Data Visualization:** Kumpulkan data nyata (misal: data penjualan, hasil survey). Gunakan AI untuk menentukan chart terbaik dan buat visualisasinya.

5. **Simulasi Q&A:** Presentasi menggunakan slide yang sudah dibuat. Gunakan ChatGPT untuk simulasi tanya jawab selama 10 menit.
