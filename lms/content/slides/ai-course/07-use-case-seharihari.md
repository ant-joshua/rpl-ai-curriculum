## 🍳 1. Makan & Masak

### Prompt 1: Resep dari Bahan yang Ada

```
Saya punya bahan-bahan berikut di kulkas:
- Ayam 300 gram
- Wortel 2 buah
- Telur 3 butir
- Bawang putih
- Kecap manis

Buatkan 3 resep masakan Indonesia yang bisa dibuat
dengan bahan-bahan ini. Setiap resep sertakan:
- Nama masakan
- Takaran bahan
- Langkah memasak (maks 6 langkah)
- Tips untuk pemula
- Estimasi waktu memasak
```

### Prompt 2: Meal Prep Mingguan

```
Saya mahasiswa yang sering makan di luar karena malas masak.
Buatkan rencana meal prep 5 hari (Senin-Jumat) dengan aturan:
- Budget: maks Rp 100.000/minggu
- Waktu masak: maks 30 menit per sesi
- Menu harus bergizi seimbang
- Bisa dimasak sekali untuk 2-3 hari

Format output:
| Hari | Menu Makan Siang | Menu Makan Malam | Bahan | Estimasi Biaya |
```

### Prompt 3: Ide Jualan Makanan

```
Saya ingin mulai jualan makanan dari rumah dengan:
- Modal awal: Rp 2.000.000
- Peralatan: kompor gas, wajan, rice cooker, Tupperware
- Target: kos-kosan dan mahasiswa
- Lokasi: dekat kampus

Buatkan:
1. 5 ide makanan yang modalnya di bawah Rp 2 juta
2. Estimasi biaya bahan per porsi
3. Harga jual yang kompetitif
4. Strategi pemasaran gratis
5. Rencana 1 bulan pertama
```

### Prompt 4: Diet & Nutrisi

```
Saya ingin pola makan lebih sehat tapi:
- Saya tidak suka sayuran hijau
- Budget makan: Rp 50.000/hari
- Saya tinggal di kos (masak sederhana)
- Alergi: makanan laut

Buatkan panduan makan sehat 7 hari yang:
- Menghindari sayuran hijau tapi tetap bergizi
- Menggunakan alternatif nutrisi yang tersedia
- praktis untuk anak kos
- Enak dan variatif (tidak membosankan)
```

## 💰 2. Keuangan & Budget

### Prompt 1: Budget Bulanan

```
Saya fresh graduate dengan gaji Rp 6.000.000/bulan.
Pengeluaran tetap:
- Kos: Rp 1.500.000
- Transport: Rp 500.000
- Pulsa/Internet: Rp 200.000

Buatkan budget bulanan yang sehat menggunakan aturan:
- 50% kebutuhan
- 30% keinginan
- 20% tabungan/investasi

Rincikan per kategori dengan nominal pasti.
Sertakan tips menabung untuk pemula.
```

### Prompt 2: Rencana Bebas Hutang

```
Saya punya hutang:
- Kartu kredit: Rp 5.000.000 (bunga 2.5%/bulan)
- Pinjaman online: Rp 3.000.000 (bunga 3%/bulan)
- Hutang teman: Rp 1.000.000 (tanpa bunga)

Pendapatan: Rp 7.000.000/bulan
Budget yang bisa dialokasikan untuk bayar hutang: Rp 2.500.000/bulan

Buatkan strategi pelunasan hutang:
1. Metode snowball vs avalanche — mana yang lebih baik untuk kasus saya?
2. Jadwal pelunasan per bulan
3. Tips mengurangi pengeluaran tambahan
4. Target waktu bebas hutang
```

### Prompt 3: Tracking Keuangan Harian

```
Buatkan template Google Sheets sederhana untuk tracking
keuangan harian dengan kolom:
- Tanggal
- Kategori (makan, transport, belanja, hiburan, lainnya)
- Deskripsi
- Nominal
- Catatan

Sertakan:
1. Rumus otomatis untuk total per kategori
2. Dashboard ringkasan bulanan
3. Grafik saran untuk visualisasi
4. Alert kondisi budget habis
```

### Prompt 4: Perencanaan Investasi Pemula

```
Saya ingin mulai investasi dengan:
- Modal: Rp 500.000/bulan
- Profil risiko: konservatif (tidak suka rugi)
- Pengetahuan: nol tentang investasi
- Target: dana darurat 6 bulan pengeluaran

Buatkan panduan investasi untuk pemula:
1. Urutan prioritas sebelum investasi
2. Rekomendasi instrumen untuk modal kecil
3. Cara mulai dari nol
4. Kesalahan umum pemula
5. Checklist kapan boleh mulai investasi
```

## 📅 3. Perencanaan Jadwal

### Prompt 1: Jadwal Harian Produktif

```
Buatkan jadwal harian optimal untuk saya:
- Bangun: 06.00
- Kerja/kuliah: 08.00-17.00
- Waktu luang: 17.00-22.00
- Tidur: 23.00

Kegiatan yang harus masuk jadwal:
- Olahraga (minimal 30 menit)
- Belajar coding (1 jam)
- Waktu keluarga/teman
- Istirahat (jangan skip!)
- Hobi (baca/musik)

Prinsip: Deep work di jam produktif, istirahat yang cukup.
Format: tabel per jam dengan aktivitas dan durasi.
```

### Prompt 2: Jadwal Kuliah & Skripsi

```
Saya mahasiswa semester 7 dengan jadwal:
- Kuliah: Senin & Rabu (08.00-14.00)
- Kerja paruh waktu: Selasa & Kamis (09.00-13.00)
- Skripsi: harus progress minimal 2 halaman/minggu
- Self-care: olahraga, sosial, istirahat

Buatkan jadwal mingguan yang:
- Mengakomodasi semua komitmen
- Ada waktu fokus untuk skripsi (minimum 2 jam/hari)
- Weekend ada time off (tidak ada kuliah/kerja)
- Realistis dan bisa dijalankan konsisten
```

### Prompt 3: Project Management

```
Saya harus menyelesaikan project dalam 4 minggu:
- Minggu 1: Research & planning
- Minggu 2: Development bagian 1
- Minggu 3: Development bagian 2 & testing
- Minggu 4: Final testing & deployment

Breakdown mingguan menjadi task harian dengan:
- Estimasi waktu per task
- Deadline per task
- Buffer untuk contingencies
- Checkpoint per minggu
- Risk mitigation per phase
```

## 📧 4. Komunikasi & Email


```
Tuliskan surat pengunduran diri profesional untuk:

Sertakan:
```

### Prompt 3: Follow-Up Setelah Meeting

```
Saya baru selesai meeting dengan client potensial.
Isi meeting:
- Mereka tertarik dengan layanan konsultasi kami
- Minta proposal detail minggu depan
- Budget mereka: Rp 100-200 juta

Tuliskan follow-up email yang:
- Mengucapkan terima kasih atas waktu mereka
- Merangkum poin-poin penting meeting

- Tunjukkan excitement dan profesionalisme
```

## 💡 5. Brainstorming

### Prompt 1: Ide Konten Media Sosial

```
Saya punya bisnis skincare lokal untuk kulit berminyak.
Target: wanita usia 18-28 tahun
Platform: Instagram & TikTok

Buatkan 20 ide konten untuk 1 bulan:
- 5 edukasi (tips, myth buster, ingredients)
- 5 engaging (polls, quizzes, challenges)
- 5 product showcase (before/after, review)
- 5 behind the scenes (proses pembuatan, tim)

Setiap ide sertakan:
- Judul/caption hook
- Format (reels, carousel, story, static)
- Estimasi engagement
```

### Prompt 2: Brainstorm Solusi Masalah

```
Masalah: Toko online saya conversion rate rendah (1.2%).
Data: 10.000 visitor/bulan, hanya 120 transaksi.
Target: Meningkatkan ke 3% dalam 2 bulan.

Brainstorm 15 solusi potensial, dikelompokkan berdasarkan:
1. Quick wins (bisa dilakukan minggu ini)
2. Medium-term (1-2 bulan)
3. Long-term (3+ bulan)

Untuk setiap solusi:
- Estimasi dampak (tinggi/sedang/rendah)
- Biaya implementasi (gratis/rp/rp++)
- Kemudahan implementasi (mudah/sedang/sulit)
```

### Prompt 3: Nama Bisnis/Produk

```
Saya ingin membuka:
- Bisnis: Kedai kopi specialty
- Lokasi: Depok, dekat kampus UI
- Target: Mahasiswa & young professionals
- Konsep: Cozy, Instagram-worthy, affordable

Buatkan 20 ide nama kedai kopi dengan:
- Nama yang catchy dan mudah diingat
- Bisa jadi hashtag
- Ada cerita/arti di balik nama
- Bisa didaftarkan sebagai brand

Setiap nama sertakan:
- Arti makna
- Kenapa nama ini works
- Contoh tagline
```

```
├── Cek rencana hari ini dengan AI
```

### Tips Memaksimalkan AI Harian

| Tips | Penjelasan |
|------|-----------|
| **Simpan prompt favorit** | Buat file khusus untuk prompt yang sering dipakai |
| **Spesifik situasimu** | Semakin spesifik konteks, semakin bagus hasilnya |
| **Iterasi, jangan puas** | Resep pertama belum tentu yang terbaik |
| **Cross-check info penting** | Jangan langsung percaya angka/resep/kode AI |
| **Gunakan memory** | Kasih tahu AI tentang preference kamu |
| **Variasi platform** | ChatGPT untuk kreatif, Claude untuk analisis |

## 🔑 Key Takeaways

1. **AI untuk SEMUA aspek kehidupan** — tidak hanya kerja/coding, tapi juga masak, olahraga, traveling, self-care
2. **Prompt yang spesifik = hasil yang berguna** — semakin detail situasimu, semakin relevan jawaban AI
3. **Gunakan AI sebagai thinking partner** — brainstorming, refleksi, dan decision making bukan hanya tentang fakta
4. **Mulai dari kebutuhan nyata** — pilih 1-2 use case yang paling relevan dan praktikkan sampai jadi kebiasaan
5. **AI adalah alat — kamu yang mengontrol** — gunakan dengan bijak, verifikasi informasi penting, dan tetap jadi decision maker
