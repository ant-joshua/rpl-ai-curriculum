## 🏋️ Latihan 3: Bandingkan 3 Model AI dengan Prompt yang Sama

**⭐⭐ Kesulitan:** Sedang | **⏱️ Waktu:** 15 menit

### Instruksi

Pilih **1 prompt** dari daftar berikut dan kirim ke **3 AI berbeda**. Bandingkan hasilnya secara detail.

### Prompt Pilihan (pilih salah satu)

**Pilihan A — Analisis:**
> "Analisis kelebihan dan kekurangan belajar online vs belajar di kelas untuk mahasiswa Indonesia"

**Pilihan B — Kreatif:**
> "Buat cerita pendek 100 kata tentang seorang petani Indonesia yang menemukanAI di ladangnya"

**Pilihan C — Praktis:**
> "Buat rencana diet 1 minggu untuk mahasiswa dengan budget Rp 50.000/hari"

### Platform yang Harus Dibandingkan

1. **ChatGPT** (chat.openai.com) — pilih model GPT-4o (gratis) atau GPT-3.5
2. **Claude** (claude.ai) — pilih Claude 3.5 Sonnet
3. **Gemini** (gemini.google.com) — pilih Gemini 2.0 Flash

### Tabel Perbandingan

| Kriteria | ChatGPT | Claude | Gemini |
|---|---|---|---|
| **Kecepatan jawaban** | | | |
| **Kedalaman analisis** | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ |
| **Kreativitas** | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ |
| **Akurasi fakta** | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ |
| **Kemudahan bahasa** | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ | ⭐/⭐⭐/⭐⭐⭐ |
| **Panjang jawaban** | Pendek/Sedang/Panjang | Pendek/Sedang/Panjang | Pendek/Sedang/Panjang |
| **Format rapi?** | Ya/Tidak | Ya/Tidak | Ya/Tidak |
| **Favoritmu?** | ✅ atau ❌ | ✅ atau ❌ | ✅ atau ❌ |

### Contoh Hasil Perbandingan

```
Prompt: "Analisis belajar online vs di kelas"

ChatGPT: 4 paragraf, terstruktur dengan heading, ada bullet points,
         analisis seimbang, ada data umum tentang efektivitas.
         
Claude: Lebih panjang, nuansa lebih kaya, mempertimbangkan konteks
        Indonesia, ada rekomendasi personal untuk mahasiswa.
        
Gemini: Ringkas, langsung ke poin, ada tabel perbandingan visual,
        tapi kurang kedalaman analisis.

Kesimpulan: Untuk tugas analisis, saya lebih suka [X]
```

### Tugas Refleksi

Jawab dalam 3 kalimat:
1. Platform mana yang hasilnya paling bagus untuk prompt ini?
2. Platform mana yang paling cepat merespons?
3. Apakah ada perbedaan signifikan antara ketiganya?

## 🏋️ Latihan 4: Tabel Perbandingan Model AI

**⭐⭐ Kesulitan:** Sedang | **⏱️ Waktu:** 10 menit

### Instruksi

Pilih **1 use case** dari daftar berikut, lalu buat tabel perbandingan model AI yang cocok untuk use case tersebut.

### Use Cases (pilih salah satu)

| No | Use Case | Deskripsi |
|---|---|---|
| A | Menulis artikel blog | Buat konten blog yang SEO-friendly |
| B | Debug kode programming | Perbaiki error di kode Python/JS |
| C | Terjemahan bahasa | Terjemahkan dokumen Indonesia → Inggris |
| D | Buat presentasi | Susun materi presentasi yang menarik |
| E | Analisis data | Analisis data penjualan dari CSV |

### Template Tabel

Berdasarkan use case yang kamu pilih, isi tabel ini:

| Model AI | Kelebihan untuk Use Case Ini | Kekurangan | Harga | Cocok untuk Pemula? |
|---|---|---|---|---|
| ChatGPT-4o | | | Gratis (limited) | Ya |
| Claude 3.5 | | | Gratis (limited) | Ya |
| Gemini 2.0 | | | Gratis | Ya |
| Llama 3.1 | | | Gratis (local) | Tidak |
| Mistral | | | Gratis | Tidak |

### Contoh Isian (Use Case: Menulis Artikel Blog)

```
| ChatGPT-4o   | Artikel well-structured, SEO-friendly | Terkadang generic | Gratis | ✅ Ya |
| Claude 3.5   | Writing quality tinggi, nuansa natural | Kurang cepat | Gratis | ✅ Ya |
| Gemini 2.0   | Integrasi Google Search, fakta terkini | Kurang kreatif | Gratis | ✅ Ya |
| Llama 3.1    | Gratis tanpa batas, bisa offline       | Perlu setup       | Gratis | ❌ Tidak |
```

### Minta Bantuan AI

Ketik ke ChatGPT/Gemini:
```
Bandingkan model AI berikut untuk [use case yang kamu pilih]:
ChatGPT-4o, Claude 3.5 Sonnet, Gemini 2.0 Flash
Buatkan dalam format tabel markdown dengan kolom: Model, Kelebihan, Kekurangan, Harga, Rating.
```

Lalu bandingkan hasil AI dengan penilaianmu sendiri!
