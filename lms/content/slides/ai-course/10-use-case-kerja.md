### Kategori 4: Analisis Data Bisnis

**Prompt 8 — Analisis Penjualan:**
```
Saya punya data penjualan 6 bulan terakhir (format CSV):
- Kolom: tanggal, produk, jumlah, harga, total, region

Tolong buatkan kode Python untuk:
1. Total penjualan per bulan
2. Top 5 produk terlaris
3. Perbandingan penjualan per region
4. Tren penjualan (naik/turun)
5. Visualisasi yang relevan
```

```python
import pandas as pd
import matplotlib.pyplot as plt

# Load data
df = pd.read_csv('penjualan.csv')
df['tanggal'] = pd.to_datetime(df['tanggal'])

# Total penjualan per bulan
monthly = df.groupby(df['tanggal'].dt.to_period('M'))['total'].sum()
print("=== Penjualan Bulanan ===")
print(monthly)

# Top 5 produk
top_products = df.groupby('produk')['total'].sum().nlargest(5)
print("\n=== Top 5 Produk ===")
print(top_products)

# Visualisasi
fig, axes = plt.subplots(1, 2, figsize=(14, 5))
monthly.plot(kind='bar', ax=axes[0], title='Penjualan Bulanan')
top_products.plot(kind='barh', ax=axes[1], title='Top Produk')
plt.tight_layout()
plt.savefig('laporan_penjualan.png')
plt.show()
```


## Key Takeaways

1. **AI mempercepat pekerjaan administratif** — email, meeting notes, laporan
2. **Data-driven decisions** — gunakan AI untuk analisis dan visualisasi data
3. **Manajemen proyek jadi lebih terstruktur** — break down, sprint planning, SOP
