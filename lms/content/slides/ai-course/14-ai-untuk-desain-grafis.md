## 2. Canva AI

### Fitur Unggulan Canva AI

| Fitur | Deskripsi | Contoh Penggunaan |
|-------|-----------|-------------------|
| **Magic Design** | Generate desain dari prompt | Poster, undangan, logo |
| **Magic Write** | Generate teks konten | Caption, deskripsi |
| **Magic Eraser** | Hapus objek dari gambar | Hapus watermark, objek |
| **Magic Edit** | Edit dengan instruksi teks | Ganti warna, tambah objek |
| **Text to Image** | Generate gambar dari teks | Ilustrasi, background |
| **Magic Resize** | Resize untuk semua platform | IG, FB, Twitter, YouTube |

### Langkah-langkah Canva AI

```
1. Buka canva.com → buat akun gratis
2. Pilih "Presentasi" / "Poster" / "Social Media"
3. Gunakan Magic Design:
   - Klik "Magic Design" di sidebar
   - Ketik deskripsi desain yang diinginkan
   - Pilih dari hasil yang di-generate
4. Customize:
   - Edit teks (klik double-click)
   - Ganti gambar (drag & drop atau dari library)
   - Ubah warna (klik elemen → color picker)
   - Tambah efek (blur, shadow, dll)
5. Download sebagai PNG, JPG, atau PDF
```

**Prompt Canva Magic Design:**
```
"Poster workshop Python programming untuk mahasiswa,
warna biru dan oranye, modern dan minimalis,
ada ikon coding dan laptop"
```

**Prompt Text to Image Canva:**
```
"A professional workspace with laptop showing code,
coffee cup, and plants, minimal aesthetic,
warm lighting, photorealistic"
```

## 3. Midjourney & DALL-E

### Prompt Engineering untuk Image Generation

#### Struktur Prompt yang Efektif

```
[Subjek] + [Gaya] + [Lingkungan] + [Pencahayaan] + [Komposisi] + [Kualitas]
```

| Komponen | Contoh |
|----------|--------|
| **Subjek** | A young Indonesian woman, a futuristic city |
| **Gaya** | Watercolor, pixel art, photorealistic, anime |
| **Lingkungan** | In a cozy cafe, on a mountain top |
| **Pencahayaan** | Golden hour, neon lights, soft studio |
| **Komposisi** | Close-up, wide angle, bird's eye view |
| **Kualitas** | 4K, detailed, professional, award-winning |

### Prompt Template untuk Berbagai Kebutuhan

**Prompt 1 — Background/Pemandangan:**
```
A serene tropical beach at sunset, palm trees swaying,
golden hour lighting, crystal clear water,
photorealistic, 4K, ultra detailed
```

**Prompt 2 — Ilustrasi Product:**
```
A sleek modern smartphone floating in mid-air,
surrounded by colorful abstract shapes,
dark background, product photography style,
studio lighting, 3D render, ultra realistic
```

**Prompt 3 — Avatar/Profile:**
```
Professional headshot of a young Indonesian tech worker,
clean white background, soft studio lighting,
confident smile, wearing casual business attire,
photorealistic, high resolution
```

**Prompt 4 — Social Media Content:**
```
Flat design illustration of a person learning to code
on a laptop, surrounded by floating code symbols,
vibrant blue and green color palette,
minimalist style, vector art quality
```

### Tips Prompt Engineering

| Tips | Penjelasan | Contoh |
|------|-----------|--------|
| **Spesifik** | Semakin detail, semakin akurat | "red rose" → "deep crimson rose with dewdrops" |
| **Negatif prompt** | Exclude yang tidak diinginkan | "--no text, watermark, blurry" |
| **Aspect ratio** | Atur rasio gambar | "--ar 16:9" untuk landscape |
| **Style reference** | Referensi gaya tertentu | "--style raw" untuk Midjourney |
| **Weight** | Utamakan komponen tertentu | "::2" untuk menambah weight |

## 5. Remove Background & Editing

### remove.bg Workflow

```
1. Buka remove.bg
2. Upload gambar (klik "Upload Image")
3. AI otomatis hapus background (2-3 detik)
4. Download hasilnya
5. Gunakan di Canva/Figma untuk composite
```

### Use Cases Remove.bg

| Kebutuhan | Contoh |
|-----------|--------|
| **Foto Profil** | Hapus background untuk LinkedIn/WhatsApp |
| **Product Photo** | Background putih untuk e-commerce |
| **Collage** | Gabungkan beberapa foto tanpa background |
| **Presentasi** | Foto pembicara tanpa background berantakan |
| **Sticker** | Buat stiker dari foto orang/produk |

## 6. Logo Design dengan AI

**Prompt 5 — Logo Teknologi:**
```
Create a modern, minimalist logo for a tech startup called
"NexCode". Colors: deep blue (#1E3A5F) and electric green (#00E676).
Style: geometric, clean lines, tech-forward.
The logo should incorporate both letters N and C subtly.
No text, icon only, suitable for app icon.
```

**Prompt 6 — Logo Startup:**
```
Design a logo for "EduLearn", an online education platform.
Style: friendly, approachable, modern
Colors: orange and navy blue
Elements: book + graduation cap + digital elements
Suitable for both light and dark backgrounds
Vector style, scalable
```

### Tips Desain Logo dengan AI

1. **Mulai dengan keywords** — tentukan gaya, warna, elemen
2. **Generate banyak variasi** — buat 5-10 opsi
3. **Refine yang terbaik** — pilih 1-2 dan minta variasi
4. **Test di berbagai ukuran** — pastikan terlihat jelas dari kecil
5. **Minta file vector** — SVG untuk scalable

## Combining AI Design Tools

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ ChatGPT      │    │ Midjourney   │    │ Canva AI     │
│ (Ideas &     │───▶│ (Generate    │───▶│ (Assemble &  │
│  Prompting)  │    │  Images)     │    │  Design)     │
└──────────────┘    └──────────────┘    └──────────────┘
                                                 │
        ┌────────────────────────────────────────┘
        ▼
┌──────────────┐    ┌──────────────┐
│ remove.bg    │───▶│ Figma        │
│ (Cleanup)    │    │ (Final Touch)│
└──────────────┘    └──────────────┘
```

### Workflow Desain Lengkap

```
1. RESEARCH (5 menit)
   • ChatGPT: Kumpulkan inspirasi & referensi
   • ChatGPT: Buatkan prompt untuk image generation

2. GENERATE (10 menit)
   • Midjourney/DALL-E: Generate gambar & ilustrasi
   • Canva AI: Generate layout & template
   • remove.bg: Hapus background dari foto

3. ASSEMBLE (15 menit)
   • Canva: Gabungkan elemen, tambahkan teks
   • Canva: Adjust warna, font, spacing
   • Canva: Magic resize untuk berbagai platform

4. REFINE (10 menit)
   • Figma: Fine-tune layout & alignment
   • Canva: Export dalam berbagai format
   • Cek di mobile & desktop
```

## Prompt Engineering Cheat Sheet

### Struktur Prompt Desain

```
[Jenis desain] + [Subjek] + [Gaya] + [Warna] + [Elemen] + [Kualitas]
```

### Contoh Prompt Berbagai Kebutuhan

| Kebutuhan | Prompt Template |
|-----------|----------------|
| **Poster Event** | "[Acara] poster, [tema], [warna], [style], [elemen], modern, 300dpi" |
| **Social Media** | "[Platform] post about [topik], [style], [warna], engaging, [size]" |
| **Logo** | "[Nama brand] logo, [industri], [style], [warna], [elemen], minimal" |
| **Thumbnail** | "YouTube thumbnail for [judul video], [ekspresi], [warna], bold text, 1280x720" |
| **Banner** | "[Platform] banner for [akun], [topik], [warna], [style], [ukuran]" |
| **Infographic** | "Infographic about [topik], data points: [jumlah], [style], clean layout" |

### Negative Prompt (Yang Harus Dihindari)

```
--no text, watermark, blurry, low quality, distorted,
   extra fingers, bad anatomy, ugly, deformed,
   duplicate, error, cropped, out of frame
```

## Key Takeaways

1. **Canva AI adalah starting point terbaik** — gratis, mudah, lengkap
2. **Prompt engineering adalah skill kunci** — semakin spesifik, semakin bagus hasilnya
3. **Gabungkan beberapa tools** — AI generate → Canva assemble → Figma refine
4. **remove.bg sangat berguna** — untuk foto produk, profil, dan composite
5. **Brand consistency** — gunakan AI untuk membuat brand guidelines
6. **Practice makes perfect** — coba berbagai style dan prompt
